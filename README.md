## ✨ 定制特性

本分支在上游全功能的基础上，重点新增了以下特性：

- 🚀 **Android 6 完美兼容**：修复原版在 Android 7 以下设备打开即闪退的问题。
- 🔤 **自定义弹幕字体**：支持直接加载手机本地 `.ttf` / `.otf` 字体，彻底解决字形发飘与日文字库 Fallback。
- 📦 **无损覆盖更新**：内置固定签名配置，后续更新直接覆盖安装，免去卸载重装导致的配置丢失。
